# Kova Studio

Official compiled Windows program releases. The application source code is private and is not stored in this repository.

Download **KovaStudio.zip** from [the latest release](https://github.com/ZeroS-dev/Kova-Studio-Updates/releases/latest), extract it and run **KovaStudio.exe**. Updates are available in the application settings without a GitHub account or token.

Only the owner publishes official updates. This repository contains release packages and their SHA-256 update descriptors.
